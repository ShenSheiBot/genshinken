# 正文图版与扫描稿系统治理方案

状态：实施完成，待提交部署
记录日期：2026-08-21

## 目标与边界

本方案处理 337 组公开内容视觉审阅后确认的三类共同问题，并登记需要单篇处置的边角问题。目标不是压缩图片数量，也不是把每篇文章改造成特殊页面，而是让已有编辑意图可靠进入网页：

1. 图片宽度提示必须真实生效；
2. 图题、人物、书封、二维码等角色必须具有明确语义；
3. 仅因公众号排版限制而发表为整页扫描图的正文，应恢复为结构化网页文字；
4. 只有版面本身构成研究对象或无法忠实重排时，才保留影印阅读形态。

不自动裁切图片，不根据像素白边猜测作者意图，不为稀薄原稿补造书目、封面或说明，也不把可选的视觉增强写成内容缺陷。

## 已确认的共同根因

### A. 裸图片的百分比宽度提示失效

当前 `"=25%"` 至 `"=100%"` 只在 `[图题]`、`[人物]` 等语义转换中消费。普通 Markdown 图片上的同一提示残留为无效 `title`，浏览器仍按原始尺寸上限或正文满宽显示。

现状统计：

- 中文正文 37 个文件、132 张图片带有未被消费的百分比宽度提示；
- 加入现有英日译文后为 43 个文件、152 张图片；
- 受影响对象包含书封、人物肖像、海报、二维码、角色设计和论证图片。

实施：

1. 让裸图片在不生成图题的前提下消费合法百分比宽度提示；可以给图片或其仅图段落写入稳定 class/data 属性，但不得把 `alt` 暴露为图题。
2. 保留 `[图题]`、`[人物]`、`[图组]`、`[幻灯]` 的既有语义职责；宽度和图题语义相互独立。
3. 增加渲染回归：合法宽度被消费、非法宽度失败、输出不得残留字面 `=NN%` 或同名 `title`。
4. 修复实现后重新枚举 132 张中文图片；不能仅依赖共同修复，因为没有提示的书封、肖像和二维码仍需单篇定宽。

终态：公开 HTML 中每个合法百分比提示都对应实际宽度语义；无效提示数量为零。

### B. 旧式斜体图题尚未迁移

全站有 78 篇、403 处“斜体短段紧邻图片”的候选，其中至少 23 篇、120 处具有“图 1／表 2／书封／来源”等强图题特征。该集合包含少量真正的正文、题记和作者说明，不能机械全改。

实施：

1. 生成只读候选报告，记录文件、行号、图片方向和说明文字；不以候选命中自动改稿。
2. 先迁移强特征图题，再人工检查其余候选。图题使用 `[图题]`；补充出版信息、来源或解释使用 `[图注]`。
3. 将确定性模式纳入门禁，包括 `*图1。*`、`*图 1：……*`、`*表2。*` 等紧邻图片的旧式写法。
4. 不把普通强调段、作者按、译者按或图片之后继续展开的论证误改为图题。

终态：确定性旧图题模式为零；人工候选均有迁移或保留裁决。

### C. 平台替代型扫描页被误当作最终正文

确认有 46 页整页扫描图只是在公众号中承载正文：

| 页面 | 页数 | 目标形态 |
| --- | ---: | --- |
| [SEP：组合性](https://preview.labonroof.top/posts/sep-compositionality) | 23 | 结构化正文、标题、公式、链接与内嵌小图 |
| [卡尔纳普补充词条 C](https://preview.labonroof.top/posts/sep-rudolf-carnap-supplement-c-inductive-logic) | 13 | 结构化正文、标题、公式、脚注与图表 |
| [卡尔纳普补充词条 E](https://preview.labonroof.top/posts/sep-rudolf-carnap-supplement-e-scientific-theory-reconstruction-part-3) | 10 | 结构化正文、标题、公式、脚注与图表 |

本地相邻仓库 `../pdf-ocr-service` 作为转录引擎。它输出逐页原始／净化 HTML、Markdown、阅读顺序、块标签、bbox 和图片裁块；它不负责跨页合并、章节判断、脚注闭合或出版级润色。

实施顺序：

1. 将《组合性》代表页临时合成 PDF，作为最小真实纵切。
2. 在本地 LAN 直接调用 Chandra 的 OpenAI 兼容端点，保存逐页 JSON、HTML、Markdown、bbox 和裁图；公共任务层的邀请码与存储接口不参与编辑流程。
3. 合并跨页段落，恢复 `h2/h3`、列表、表格、公式、链接、脚注和图题；禁止把 OCR 的页边界当作语义边界。
4. 逐页对照扫描图，确认每个可见正文块已保留或有明确裁决；OCR 结果未经目检不得替换扫描页。
5. 渲染前三页的结构化网页并验收桌面和移动版。通过后处理剩余 43 页。
6. 原扫描页保留在 Git 外归档／R2 和专篇 evidence 中；正文不再重复展示整页扫描图。必要时提供来源影印入口，但不让影印页成为 canonical 正文。

2026-08-21 纵切结果：`/health` 与 `/v1/models` 均返回 200，单页耗时约 19–23 秒。普通正文、标题、行内／块公式、尾注和内嵌图片裁块均可用。OCR 无法从位图恢复真实链接地址，页末跨页句也必须在编辑阶段拼接；模型生成的图片描述属于待校订素材，不得直接当作原文发表。默认模型 prompt 保持不变，最终质量由逐页对照与网页编辑负责。

2026-08-21 实施结果：46页已全部完成OCR底稿、逐页核校和语义重排。《组合性》恢复正文、23组尾注及3幅正文小图；补充词条C恢复正文、11组块引文和8组陈列公式；补充词条E恢复正文、九组来源引文和两条陈列公式。三篇均不再以整页扫描图作为canonical正文，原扫描继续留在Git外档案／R2和专篇证据链中。

最小验收：页数闭合、无漏段、无重复段、标题层级正确、公式和链接可用、内嵌图片保真、脚注调用与定义闭合、OCR 订正均有来源图支持。

《噪声的信号》是漫画／图像论文，不属于上述 OCR 重排：其图像本身就是正文，应另行评估宽版、放大或漫画阅读模式。

## 已完成的版式增强，独立于缺陷修复

- 《超人幻想年表》：时间轴。
- 女性主义理论合辑：阅读路径卡片。
- 日本亚文化与社会评论书籍推介：不增补资料的紧凑书单。
- 动画评论资料目录：资源卡列表，原有标题、链接、类型和说明全部保留。
- 日本 00 年代动漫批评播客：节目头部与 show notes。
- 读者群公告：紧凑二维码／联络卡。
- 《噪声的信号》：漫画／图像论文宽版阅读。

七种形态共用一套显式 `[版式:…]` 区块转换，不按题名、链接数或图片数猜测，也没有七个单篇组件。桌面 1440×900 与移动端 390×844 实页截图均无横向溢出；对应 Playwright 回归在 Desktop Chrome 与 Pixel 7 两个项目共 20 项通过。

## 实施顺序与发布批次

1. 修复裸图宽度提示并加入回归测试。
2. 处理“确认应修”的书封、肖像、二维码和竖图；视觉复核桌面 1440px、窄桌面 1024px、移动端。
3. 迁移确定性旧图题，复核全部候选报告。
4. 完成《组合性》三页 OCR 纵切，再处理 46 页扫描稿。
5. 从可选增强中依次试做时间轴、阅读路径和漫画阅读；每类先验收一个页面。

每个批次分别提交，避免将共同渲染器修改、几十篇内容迁移和全新版式混成无法回滚的大提交。

## 门禁与人工验收

自动门禁至少覆盖：

- 合法 `=NN%` 提示全部被消费；
- 非法宽度失败；
- 裸图不产生虚构图题；
- 语义书封缺少宽度时给出可操作诊断；人物肖像与二维码必须在专篇裁决中定宽，不能仅凭替代文本可靠自动分类；
- 任何图片相邻的独立斜体均须迁移为 `[图题]`／`[图注]`，或用 `<!--standalone-emphasis-->` 留下明确保留裁决；
- OCR 重排稿的脚注、链接、图片和页面来源合同闭合。

浏览器验收覆盖：

- 图片不因自然尺寸意外接近整屏；
- 图题与图版保持同一语义块；
- 书封、人物和二维码尺度与正文角色相称；
- 扫描重排后的文字可搜索、复制并响应式排版；
- 公式、表格、链接、脚注和内嵌小图可用；
- 没有横向溢出、空白假洞或移动端不可读缩放。

- `verify:typography` 全量渲染 337 篇中文正文与 31 份英日译文；旧式邻图斜体、语义标记泄漏与非法宽度均为零。

- OCR 数学专项 Playwright 回归在 Desktop Chrome 与 Pixel 7 共 8 项通过；行内公式字号与正文一致，陈列公式局部滚动而不撑宽页面。
- 七类显式版式的 20 项 Playwright 回归通过，时间轴含机器可读 `<time>`，阅读路径保留 10 个来源入口，紧凑书单保留原有 3 项推荐。
