# 目录进度栏（TocRail）设计文档

> 文章页左缘的目录 × 阅读进度部件。方案代号「标尺 / SCALE」。
> 代码：`app/components/TocRail.tsx` + `app/globals.css` 末尾「目录进度栏」一节；由 `app/posts/[slug]/page.tsx` 挂载。

## 设计思路

- **长在页面里，而不是贴一个目录框。** 站点是"瑞士工程制图 / brutalist editorial"语汇：发丝构造线、mono 标注、极少量 crimson。进度栏取同一语汇——一条 1px 发丝线作全程标尺，已读段以 accent 变实，读感接近图纸上的标注线，而非独立的 UI 控件。
- **进度与目录共用一个坐标系。** 点位 = 标题在全文中的真实位置（按比例映射到栏高），进度线扫过某个点，即表示该节已读。不存在"进度条 + 另一套目录"的两套坐标。
- **三级点位语汇**（最多三级）：
  - ● 实心圆 = 该篇第一级标题
  - ○ 空心环 = 第二级
  - 芯点（外圈镂空、仅余小实心核）= 第三级
  - 注释 / 文献区默认同 ● 实心圆（悬停签以「注」「文」区分）
- **级别自适应**：取该篇*实际出现*的前三级标题。《列宁之争》为 h2/h3 两级（●/○），《何为东亚》正文从 h1 起。更深层级不入栏。
- **与 `ReadingRail`（每十行里程碑数字）互补共存**：里程碑贴正文版心两侧，本部件贴视口左缘，互不占位。

## 行为规范

- **停驻（类 sticky）**：页首时栏顶（百分比读数）与正文首行对齐；随下滑跟随正文上移；栏顶到达顶栏下 90px 后停驻转为固定。栏高恒定 `calc(100vh - 120px)`，点位不因停驻漂移。
- **量程**：正文首行 → 「完 / FIN」行。阅读线（视口上沿下 42% 处）越过完/FIN 即 100%；滚到页面绝对底部兜底为 100%。注释、文献计入量程。
- **交互**：悬停点位浮出标题签（纯 CSS，`mono 级别标注 + 衬线标题`，超长省略号）；点击跳转（`scroll-margin` 对齐顶栏下 84px，尊重 `prefers-reduced-motion`）。
- **状态色**：未读 `--ink-faint`，已读 `--ink`，当前节 `--accent` 并放大 1.3。点位以 `box-shadow: 0 0 0 3px var(--bg)` 在线上打出豁口。
- **窄屏退化**：`<1180px` 时整栏隐藏（再窄会与正文里程碑数字相撞），改为顶栏下 2px 细进度条；`@media print` 全部隐藏。
- **可访问性**：`<nav aria-label="章节导航">`，点位为真实 `<button>`（26px 命中区），`aria-current` 标当前节，装饰元素 `aria-hidden`。

## 视觉约束（务必遵守）

- 颜色**只用主题令牌**（`--ink / --ink-faint / --hair / --accent / --bg`），明暗主题自动成立；不引入新色值。
- **无硬阴影、无圆角容器**；线用 1px 发丝，变实段 3px。crimson 保持"极少量"：全页仅进度实段 + 当前节一个点 + 悬停签的级别标注。
- 字体沿用 `--f-mono`（百分比、级别标注）与 `--f-cjk-serif`（标题签），不新增字族。

## 实现要点

- 测量以 `getBoundingClientRect + scrollY` 为准；`resize` / `ResizeObserver` / `document.fonts.ready` / 图片 `load` / `.enter` 动画结束后重算（正文进入动画会位移 16px）。
- 滚动更新经 `requestAnimationFrame` 节流；停驻 top 每帧由 JS 设定。
- 点位重叠时保持最小 15px 间距、末端超出整体回收（判定已读仍按原始比例位置，不受间距调整影响）。
- 慢速网络下字体晚到会改变文档高度——已挂 `fonts.ready` 重算，勿删。

## 调参入口

- 阅读线位置：`TocRail.tsx` 内 `0.42`（视口高度比例）。
- 停驻高度：`90`（px，= 顶栏 65 + 25），与 `.toc-rail { top }`、跳转偏移 `84` 相关联。
- 退化断点：`globals.css` 中 `1179px`。
